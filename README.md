# Student Registration Form

A simple, clean student registration form built with plain HTML and CSS — no frameworks, no JavaScript.

## Preview

A small enrollment-card layout with a name field, email field, and a submit button styled like a registration slip.

## Files

```
html-css-practical/
├── README.md
├── index.html
└── style.css
```

## Features

- Semantic, accessible HTML form markup
- Custom typography pairing (Lora for headings, Inter for body/UI)
- Underline-style inputs with clear focus states
- Fully responsive down to small mobile screens
- Respects `prefers-reduced-motion`

## Usage

Clone the repo and open `index.html` directly in your browser — no build step required.

```bash
git clone <your-repo-url>
cd html-css-practical
open index.html   # or just double-click the file
```

## Tech

- HTML5
- CSS3 (custom properties, flexbox)
- [Google Fonts](https://fonts.google.com/) — Lora & Inter
